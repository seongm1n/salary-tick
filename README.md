# SalaryTick

메뉴바에서 초 단위로 번 돈이 올라가는 걸 보여주는 macOS 앱.
출근하면 숫자가 오르기 시작하고, 퇴근 시각에 멈춘다.
**오늘 / 이번 달 / 올해** 중 골라서 볼 수 있다.

```
┌ 메뉴바 ─────────────────┐
│  ⏱ ₩ 84,213             │  ← 1초마다 갱신
└─────────────────────────┘
```

## 빌드 / 실행

```sh
./build.sh install  # 빌드 + 서명 + /Applications 설치 + 실행
./build.sh run      # 빌드 + build/에서 바로 실행
./build.sh test     # 계산 로직 자체 검증
./build.sh preview  # 패널 디자인을 build/preview.png로 렌더
./build.sh          # 빌드만
pkill -x SalaryTick # 종료 (패널의 "종료" 버튼도 동일)
```

Xcode 프로젝트 없음. Command Line Tools의 `swiftc`로 `.app` 번들을 직접 조립한다.
그래서 **`@State`를 쓰지 않는다** — CLT에는 `SwiftUIMacros` 플러그인이 없어서
`@State` 확장이 빌드를 깬다. 패널 로컬 상태는 `PanelState: ObservableObject` + `@StateObject`로 받는다.
(`@AppStorage` / `@StateObject` / `@EnvironmentObject`는 매크로가 아니라 그냥 된다.)
`Info.plist`의 `LSUIElement=1` 덕분에 Dock에 안 뜨고 메뉴바에만 산다.

의존성 0개. SPM 매니페스트도 없다 — 파일 하나짜리 앱에 패키지 그래프는 과하다.

## 데이터 모델

`@AppStorage`(= UserDefaults) 4개 값이 전부. 설정 파일도 DB도 없다.

| 키 | 타입 | 기본값 |
|---|---|---|
| `annualSalary` | Int (원, **세전**) | 50,000,000 |
| `startHour` | Double (예: 9.0 = 09:00, 9.5 = 09:30) | 9.0 |
| `endHour` | Double | 18.0 |
| `workdaysPerYear` | Int | 250 |
| `scope` | String (`오늘`/`이번 달`/`올해`) | `오늘` |

## 계산

```
하루근무초    = (endHour - startHour) * 3600
초당수입      = annualSalary / (workdaysPerYear * 하루근무초)
경과초        = clamp(now, 출근, 퇴근) - 출근      // 음수면 0
오늘번돈      = 초당수입 * 경과초
진행률        = 경과초 / 하루근무초
```

기간(`scope`)에 따라 전액과 진행률만 갈아끼운다. 번 돈 = 전액 × 진행률.

| scope | 전액 | 진행률 |
|---|---|---|
| 오늘 | annual / workdays | 경과초 / 하루근무초 |
| 이번 달 | annual / 12 | (지난 평일 + 오늘 몫) / 이번 달 평일 |
| 올해 | annual | (지난 평일 + 오늘 몫) / 올해 평일 |

평일은 `Calendar.isDateInWeekend`로 하루씩 훑어 센다 (공휴일은 안 본다).
주말에 열면 "오늘 몫"은 0 — 지난 평일까지만 반영된다.
`workdaysPerYear`는 일당 계산에만 쓴다. 월/연은 연봉을 직접 나누는 게 실제 급여에 가깝다.

경계 동작:
- **출근 전** → ₩0, 패널에 "출근까지 N시간 M분"
- **근무 중** → 1초마다 증가
- **퇴근 후** → 하루치 전액에서 고정, "퇴근! 🎉"
- **주말** → 체크 안 함 (열면 그냥 진행률 0). 필요해지면 `Calendar.isDateInWeekend` 한 줄.

점심시간 차감 없음. 어차피 점심 값도 연봉에 포함돼 있다고 치자.

## 디자인

컨셉: **정교한 수입 계기판**. 차콜 바탕 위에 큰 화이트 금액과 얇은 민트 호를
배치한다. 실시간 금액이 가장 먼저 읽히고, 기간·진행률·보조 지표가 뒤를 받친다.

### 패널

- 너비 344pt, 차콜 그라데이션 배경 고정. 패널만 다크 모드로 표시한다.
- 상단에 SalaryTick 이름과 수입 현황 라벨, 그 아래 오늘 / 이번 달 / 올해 선택.
- 기간 선택은 실제 `Button`으로 구성한다. 선택 항목은 은은한 회색 면과 밝은 글씨,
  접근성 선택 상태로 구분한다.
- 게이지는 256pt의 240° 호. 3pt 선과 가는 눈금, 작은 화이트 끝점으로 진행률을 표현한다.
  마일스톤(기간 총액의 2%)에서는 호의 그림자만 잠깐 강조한다.
- 금액은 34pt SF Semibold와 `monospacedDigit`, 화이트. 숫자 전환 애니메이션을 유지하며
  긴 연간 금액은 확보된 폭 안에서 최소 75%까지 축소한다.
- 초당 수입과 기간 총액은 하나의 은은한 면 안에 정렬하고, 가는 세로선으로 구분한다.
  보조 금액도 한 줄로 표시하고 긴 값은 축소한다.
- 하단에는 접을 수 있는 설정, 세전 기준 표시와 종료 버튼을 배치한다.
  설정을 펼치면 기존 연봉·출퇴근·근무일·자동 실행 컨트롤을 사용한다.

### 메뉴바

미니 진행률 링(11pt) + 금액. 시스템 테마를 따라 `.primary` 색상을 사용하고,
`monospacedDigit()`으로 숫자 변경 시 폭의 출렁임을 줄인다.

### 앱 아이콘

`make-icon.swift`가 AppKit으로 차콜 스퀘어클, 민트 진행 호, 화이트 `₩`를 그린다.
패널의 진행 표시를 아이콘에도 이어 쓴다. `build.sh`에서 크기별 PNG와 `.icns`를 생성한다.

### 디자인 확인

```sh
./build.sh preview   # → build/preview.png
```

`ImageRenderer`가 `PanelView`를 2배 해상도 PNG로 렌더한다. 기본 프리뷰는 현재 시각과
실행 환경의 설정값을 사용한다. 화면 녹화 권한은 필요 없다. 시스템 입력 컨트롤은
오프스크린 렌더에서 생략될 수 있으므로 설정 조작은 실제 앱에서 확인한다.

커스텀 폰트나 상시 반복하는 장식 애니메이션은 추가하지 않는다.

## 검증

돈 계산이라 체크를 남겼다. `App.swift` 하단 `selfTest()`, 실행은 `./build.sh test`.

- 출근 전 = ₩0 / 퇴근 시각 = 하루치 전액 / 퇴근 후 고정 / 정중앙 = 절반
- 진행률 0.0 ~ 1.0 클램프
- 역전 구간(22시→6시), 연봉 0 → 0원
- 2026-09-14(월) 고정 날짜로 월/연 평일 수(22일 / 261일), 월 진행률, 주말 처리

`assert`가 아니라 `precondition`을 쓴다. 릴리스(`-O`) 빌드에서 `assert`는
통째로 제거돼서 테스트가 항상 통과해버린다. 테스트 프레임워크는 안 쓴다.
