# SalaryTick

메뉴바에서 초 단위로 오늘 번 돈이 올라가는 걸 보여주는 macOS 앱.
출근하면 숫자가 오르기 시작하고, 퇴근 시각에 멈춘다.

```
┌ 메뉴바 ─────────────────┐
│  ⏱ ₩ 84,213             │  ← 1초마다 갱신
└─────────────────────────┘
```

## 빌드 / 실행

```sh
./build.sh install  # 빌드 + 서명 + /Applications 설치 + 실행
./build.sh run      # 빌드 + build/에서 바로 실행
./build.sh test     # 계산 로직 자체 검증
./build.sh preview  # 패널 디자인을 build/preview.png로 렌더
./build.sh          # 빌드만
pkill -x SalaryTick # 종료 (패널의 "종료" 버튼도 동일)
```

Xcode 프로젝트 없음. Command Line Tools의 `swiftc`로 `.app` 번들을 직접 조립한다.
`Info.plist`의 `LSUIElement=1` 덕분에 Dock에 안 뜨고 메뉴바에만 산다.

## 파일

| 파일 | 역할 |
|---|---|
| `App.swift` | 전부. 앱 진입점 + 계산 + 패널 UI |
| `Info.plist` | 번들 메타데이터, Dock 숨김 |
| `build.sh` | swiftc → `build/SalaryTick.app`, 아이콘 생성, 설치 |
| `make-icon.swift` | 앱 아이콘 렌더러 (AppKit 직접 드로잉) |
| `build/preview.png` | `./build.sh preview` 결과물 — 패널 오프스크린 렌더 |

의존성 0개. SPM 매니페스트도 없다 — 파일 하나짜리 앱에 패키지 그래프는 과하다.

## 데이터 모델

`@AppStorage`(= UserDefaults) 4개 값이 전부. 설정 파일도 DB도 없다.

| 키 | 타입 | 기본값 |
|---|---|---|
| `annualSalary` | Int (원, **세전**) | 50,000,000 |
| `startHour` | Double (예: 9.0 = 09:00, 9.5 = 09:30) | 9.0 |
| `endHour` | Double | 18.0 |
| `workdaysPerYear` | Int | 250 |

## 계산

```
하루근무초    = (endHour - startHour) * 3600
초당수입      = annualSalary / (workdaysPerYear * 하루근무초)
경과초        = clamp(now, 출근, 퇴근) - 출근      // 음수면 0
오늘번돈      = 초당수입 * 경과초
진행률        = 경과초 / 하루근무초
```

경계 동작:
- **출근 전** → ₩0, 패널에 "출근까지 N시간 M분"
- **근무 중** → 1초마다 증가
- **퇴근 후** → 하루치 전액에서 고정, "퇴근! 🎉"
- **주말** → 체크 안 함 (열면 그냥 진행률 0). 필요해지면 `Calendar.isDateInWeekend` 한 줄.

점심시간 차감 없음. 어차피 점심 값도 연봉에 포함돼 있다고 치자.

## 디자인

컨셉: **"돈 세는 계기판"**. 은행 앱의 딱딱함이 아니라, 게임 스코어보드가
올라갈 때의 그 느낌. 보는 순간 숫자가 오르는 게 눈에 들어와야 한다.

### 메뉴바 라벨
- `₩ 84,213` — `.monospacedDigit()` 필수. 안 그러면 숫자 바뀔 때마다 폭이 출렁여서 옆 아이콘들이 흔들린다.
- 시스템 테마 자동 대응(다크/라이트) — 색을 박지 않고 `.primary` 계열만 쓴다.

### 패널 (클릭 시) — 타코미터

너비 320pt, 다크 판 고정(`Ink.panel`). 시스템 머티리얼을 안 쓴다 —
어두운 바탕이어야 민트가 산다.

```
        ╭───────────────╮
      ╱   ' ' ' ' '   ●  ╲      ← 채워진 호 + 끝점 글로우
     │      오늘 번 돈      │
     │     ₩90,564        │     ← 29pt, 민트→시안
     │  53% · 4시간 8분 남음 │
      ╲                  ╱
    10:00            19:00      ← 호가 트인 자리에 얹는다
   ┌────────┐  ┌──────────┐
   │  초당   │  │ 오늘 총액  │
   │  ₩5.2  │  │ ₩168,000 │
   └────────┘  └──────────┘
   › 설정
```

- **게이지**: 아래가 트인 240° 호(`Arc: Shape`). 배경 호 + `AngularGradient` 채움 +
  안쪽 눈금 41개(지나간 눈금만 민트). 채운 호 끝에 흰 점 + 시안 글로우 — 계기판 바늘 역할.
- **메인 숫자**: 29pt SF Rounded Bold + `monospacedDigit`, 민트→시안.
  `.contentTransition(.numericText())`로 1초마다 자릿수가 굴러 올라간다.
- **마일스톤**: ₩10,000 넘길 때마다 호와 숫자가 0.2초 번쩍(`glow`). 이 앱의 도파민.
- **칩 2개**: 초당 수입 / 오늘 총액. 5% 화이트 배경 + 7% 스트로크.
- **설정**: `DisclosureGroup`으로 접혀 있다. 4개 필드뿐이라 창을 따로 안 만든다.

### 메뉴바 라벨
- 미니 진행률 링(11pt) + `₩ 90,564`.
- `.monospacedDigit()` 필수. 안 쓰면 숫자 바뀔 때마다 폭이 출렁여서 옆 아이콘들이 흔들린다.
- 링은 `.primary`라 다크/라이트 메뉴바를 알아서 따라간다.

### 디자인 확인 방법

메뉴바 팝오버는 스크린샷 찍기가 번거로워서, 패널을 **오프스크린 렌더**한다.

```sh
./build.sh preview   # → build/preview.png
```

`ImageRenderer`로 `PanelView`를 그대로 PNG에 굽는다. 화면 녹화 권한도, 앱 실행도 필요 없다.
디자인 고칠 땐 이걸 돌려 보면서 잡는다.

### 안 하는 것
- runcat식 애니메이션 아이콘 (CPU 쓰고, 숫자보다 덜 중요하다)
- 상시 `TimelineView` 애니메이션 (쉬머, 드리프팅 그라데이션). 배터리를 계속 먹는다.
  번쩍임은 마일스톤 때만 0.2초.
- 커스텀 폰트 (SF Rounded가 이미 충분히 좋고 번들 용량 0)
- 패널 라이트 모드 (다크 고정. 메뉴바 라벨만 시스템을 따라간다)

### 앱 아이콘

`make-icon.swift`가 AppKit으로 1024pt PNG 한 장을 그리고, `sips`로 각 크기를
뽑아 `iconutil`이 `.icns`로 묶는다. 디자인 툴도 이미지 파일도 리포에 없다 —
색을 바꾸고 싶으면 스위프트 상수 두 줄만 고치면 된다.

민트→시안 스퀘어클 + 차콜 `₩`. 패널의 메인 숫자와 같은 그라데이션이라
아이콘과 앱이 같은 물건으로 보인다.

## 검증

돈 계산이라 체크를 남겼다. `App.swift` 하단 `selfTest()`, 실행은 `./build.sh test`.

- 출근 전 = ₩0 / 퇴근 시각 = 하루치 전액 / 퇴근 후 고정 / 정중앙 = 절반
- 진행률 0.0 ~ 1.0 클램프
- 역전 구간(22시→6시), 연봉 0 → 0원

`assert`가 아니라 `precondition`을 쓴다. 릴리스(`-O`) 빌드에서 `assert`는
통째로 제거돼서 테스트가 항상 통과해버린다. 테스트 프레임워크는 안 쓴다.
